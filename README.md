# 途迹 TUJI · 网页发布文件

网站：[打开途迹 TUJI](https://thienquynhhuynh18367-boop.github.io/tuji-travel-map-pages/)

本仓库仅保存可公开访问的网页构建文件；开发源码保留在私有仓库中。

照片、录音、文字及点亮状态存储在每位访客自己的浏览器 IndexedDB，不会上传至 GitHub。不同网站地址之间不共享浏览器数据；换网址前请在旧站导出完整备份，再在新站导入。

地图数据的来源、许可与覆盖限制见 [SOURCES](data/SOURCES.md)，依赖许可见 [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES.txt)。当前地图源缺少完整南海诸岛等几何，不能声称完整疆域展示或已通过地图审核。

对应开发版本：`f341005464cc9a6a80f6e342c141d260698f20e0`。文件校验值见 [deployment.json](deployment.json)。
